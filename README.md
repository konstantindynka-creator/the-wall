# THE WALL

Один общий пиксельный холст 96x96. Все, кто открыл ссылку, рисуют на нём вместе, вживую.

## Деплой на Render (бесплатно, без терминала)

1. Зарегистрируйся на github.com (если ещё нет аккаунта).
2. Нажми "+" вверху справа, затем "New repository". Назови `the-wall`, поставь Public, нажми "Create repository".
3. На странице нового репозитория нажми ссылку "uploading an existing file".
4. Перетащи в окно содержимое папки `pixelwall`: `server.js`, `package.json`, `render.yaml`, `.gitignore`, `README.md` и папку `public` (с файлом `index.html` внутри). Папку `node_modules` не загружай. Нажми "Commit changes".
5. Зарегистрируйся на render.com через кнопку "Sign in with GitHub".
6. "New +", затем "Web Service", выбери репозиторий `the-wall`.
7. Если Render предложит настройки, проверь: Runtime = Node, Build Command = `npm install`, Start Command = `npm start`, Instance Type = Free. Нажми "Deploy".
8. Через 2-3 минуты сверху появится адрес вида `https://the-wall-xxxx.onrender.com`. Это и есть ссылка для поста.

## Что знать

- Бесплатный тариф Render засыпает после 15 минут без посетителей. Первое открытие после сна занимает около 30-50 секунд. Перед публикацией поста открой ссылку сам, чтобы сервис проснулся.
- Рисунок сохраняется в файл каждые 10 секунд, но на бесплатном тарифе файл стирается при каждом новом деплое и иногда при перезапуске. Для постоянного хранения нужен платный диск. Для вирусного поста это не критично.
- Лимит скорости: до 40 пикселей в секунду с одного подключения. До 500 одновременных посетителей.

## Локальный запуск

    npm install
    npm start
    # открой http://localhost:3000
